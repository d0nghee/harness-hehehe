# hehehe:feature-spec

Use before implementing a discrete feature.

Write `.hehehe/feature-spec.md` and `.hehehe/done-criteria.md` with:

- user story
- behavior
- affected routes/APIs/components
- edge cases
- test plan
- rollout notes

This should be ready for `hehehe:auto-resolve`.
