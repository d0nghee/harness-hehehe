# hehehe:evaluate

Use this to score or inspect completed work.

Evaluate:

- correctness against requested behavior
- missing edge cases
- test and build coverage
- maintainability
- security and data risks
- UI workflow quality when relevant

Findings must lead with severity and file references. Claude findings are advisory until Codex checks the code.
